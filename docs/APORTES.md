# Aportes

| Módulo | Aporte |
|---|---|
| `apps/auth-api` | Identidad, JWT RS256, audiencia `activities-api` y JWKS |
| `apps/activities-api` | Cuestionarios, imágenes, salas, reglas de puntaje y WebSocket |
| `apps/web` | Aula del profesor y de los participantes |
| `apps/demo-client` | Cliente que consume las APIs por red |
| `docker-compose.yml`, `infra/` | Arranque, persistencia y observabilidad |
| `docs/`, `openspec/` | Especificación, contratos y spec archivado |
